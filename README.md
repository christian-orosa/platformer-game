# Simple 2D SFML/C++ Platformer game
## Gameplay
[▶ Watch Gameplay](https://www.youtube.com/watch?v=ivcypnG-5YA)

## How to run

1. Download the repository
2. Extract the ZIP file
3. Run `PlatformerGame.exe`

## Technologies

- C++
- SFML

## Features

- Player movement
- Player physics
- Collision detection
- Level loading
- Texture rendering

## Build

Open `PlatformerGame.sln` with Visual Studio 2022+ and build in x64 Debug or Release.

## Controls

- A → Move left
- D → Move right
- W → Jump
